# Thermostat popup installation

Follow [the HACS and manual instructions](README.md#thermostat-popup-through-hacs).
The existing backend must supply the [entity/status contract](docs/ENTITY-CONTRACT.md).
HACS installs only the browser module. For the optional dashboard sidebar app,
add this repository independently through the HA App store and follow
[the app instructions](hargassner-dashboard/DOCS.md).
